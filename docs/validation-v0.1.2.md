# openOfficetab 0.1.2 验证记录

日期：2026-10-11。环境沿用首版验证机器：Windows 11、Office Home 2024 x64，200% 缩放。本轮通过文件关联打开无个人信息的空白示例，附着真实桌面 Office，未使用界面截图或电脑操控进行视觉验收。

## 本地运行验证

`tests/lifecycle-runtime.ps1` 在 Word、Excel、PowerPoint 分别执行以下检查：

| 检查 | 结果与边界 |
| :--- | :--- |
| 最后文档关闭 | 三宿主关闭最后测试文档后，释放测试自动化引用，确认原 Office 进程退出 |
| 取消关闭 | 三宿主通过原生 BeforeClose 事件取消后保留文档；Word、Excel 在未保存状态验证 |
| PowerPoint 保存提示 | 本轮确实触发原生提示，但没有自动选择保存 / 不保存按钮；取消回归临时设置自有测试文稿 Saved 三态，再恢复未保存状态，不能当作真实未保存提示按钮验收 |
| 文档与窗口保留 | 新标签组、跨栏加入、移出与加回保留原 HWND、测试文稿及未保存编辑 |
| 多个组 | 新建独立文稿隐藏栏，加入指定组后恢复；关闭最后组内标签时保留其他独立文稿 |
| 批量范围 | 保存全部与关闭其他不影响其他组；取消关闭后停止；连续关闭两个空白文稿 |
| 跨栏合并 | 调用与鼠标释放共用的 DropTab 命令，并按实际屏幕位置命中目标栏；真实鼠标拖拽手感待人工验收 |
| 宽度 | 固定宽度修改生效；拒绝小于 80、大于 360、无效模式；取消宽度对话框的按钮交互待人工验收 |
| 恢复 | 隐藏标签栏后恢复，逐个激活窗口确认自有栏显示并对齐预留区域；后台 Excel 窗口延迟挂载不当作故障 |
| 诊断隐私 | 加载诊断字段中没有测试正文标记、文件名、路径、标题字段或句柄；原始开发状态与日志不公开上传 |

运行结果保留在本地 `artifacts/lifecycle-*.json`，仅记录宿主和通过标记，不纳入仓库。

## 构建与安装

- MSVC x64 编译通过；宽度纯计算测试验证边界、标题长度、压缩与 50 标签场景。
- 三个空白 Office 示例通过隐私检查；PowerShell 脚本通过语法检查，使用 Windows PowerShell 可读取的 UTF-8 BOM。
- 桌面用户注册成功，三个宿主的 LoadBehavior 为 3；离线诊断校验已安装 DLL 与本地输出相同。
- 打包过程校验 EXE 内嵌 DLL 与构建输出一致，发布资产另附 SHA256SUMS。
- GitHub Actions 只执行编译、示例检查、宽度测试与安装包校验，不包含桌面 Office 运行验证。

## 尚未覆盖

没有声称全部 UI 已验收。宽度与诊断对话框、真实鼠标拖拽、多显示器 DPI、受保护视图、隐藏工作簿、同一文件多视图、只读 / 云文档、Excel 编辑与计算忙、PPT 放映等仍需扩大人工回归。隐藏工作簿和受保护视图有退出保护代码，本轮没有创建这些场景实测。

多个组限同一 Office 应用实例，本次会话生效；不支持跨进程迁移或重启恢复组成员。
