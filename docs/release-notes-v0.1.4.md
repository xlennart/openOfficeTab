openOfficetab 0.1.4 修正 Word、Excel、PowerPoint 标签切换的窗口协调，并增加标签栏颜色自定义。

- 同组切换沿用点击所在窗口的当前位置和尺寸，处理窄窗口与最大化文件之间的切换；独立窗口与其他组不跟随。保留 Office 原有文档，不重挂或重新打开文件。
- OLE 占位不再接管 Office 的菜单和工具栏；窗格压缩增加归属与尺寸保护，修复控件销毁时的重复释放。
- 融合样式默认底色为 `#F0F0F0`。在 **… → 标签外观 → 标签栏颜色…** 输入六位色值或用调色板选择，支持恢复默认；深色与高对比度优先。
- README 同时展示旧款独立面板和新版融合样式，由使用者提供并审阅的三款应用截图。

构建、原生绘制 / 输入 / 窗口状态与安装包校验通过。Word 完成 8 次新建和 12 次双向切换；Excel、PowerPoint 各完成 4 次新建和 12 次切换，功能区可见性和占位布局检查通过。真实 Windows 吸附手感、调色板和取消按钮仍需人工检查；偶发问题并非全场景保证。详见 [验证记录](https://github.com/xlennart/openOfficetab/blob/v0.1.4/docs/validation.md)。

安装：保存并完全退出三款 Office，运行 `openOfficetab-0.1.4-setup-x64.exe`，或完整解压 ZIP 后运行 `Install.cmd`。安装程序不会关闭你的 Office 窗口，按当前用户注册，无需管理员权限。安装器未做代码签名，附 SHA-256 校验值。
