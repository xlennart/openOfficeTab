# openOfficetab 0.1.6 · Windows x64

为 Word、Excel、PowerPoint 添加原生文档标签。免费，MIT 开源。

## 安装

保存文档并退出三款 Office，将 ZIP 完整解压，双击 `Install.cmd`。按当前 Windows 用户注册，无需管理员权限。重新打开 Office 文档后，标签栏出现在功能区下方。

也可以从 GitHub Release 下载 EXE 安装程序，点击“安装 / 更新”。两个入口安装相同的 DLL。安装不会自动关闭 Office 窗口。

## 使用

- 点击切换，拖动排序，点击 × 或中键关闭。
- 同组切换沿用点击所在窗口的当前尺寸和位置，适配分屏；独立窗口和其他标签组不跟随。
- 标签后的 + 新建，向下箭头列出文档，… 打开设置。
- 右键“在独立窗口中显示”，将当前窗口移出标签组；原文件和未保存内容保留。
- 在独立窗口的 openOfficetab 功能区点击“加入 / 移动到标签组”，选择目标组。
- 拖出标签形成新标签组窗口，拖到另一窗口的标签栏合并；右键菜单也提供拆分与移动。
- 功能区和标签菜单可直接“新建为独立窗口”。分组仅限同一应用实例、本次会话。
- “默认标签宽度”可设置 80–360，选择固定、标题长度或空间不足时压缩。
- 拖动标签右边缘只调整该标签宽度；按 Esc 取消。已保存本地文件重开后恢复手动宽度，不修改文档内容。
- “…” → “标签外观”可选浅灰背景融合开口标签 / 独立白色面板，以及顶部 / 底部 / 无强调线；默认浅灰融合和顶部强调线。
- 融合样式默认底色为 `#F0F0F0`；“标签栏颜色…”支持输入六位十六进制颜色或使用调色板，自定义选择按用户保存。“恢复默认颜色”恢复融合浅灰 / 独立白色；深色和高对比度优先。
- 保存全部标签和批量关闭只处理当前组，保留 Office 原生保存提示。
- 关闭最后一个文档后退出应用；取消关闭、还有独立文档、隐藏工作簿或受保护视图时不会退出。
- “加载诊断”和“导出脱敏诊断”不包含文件名、路径、正文、账号或原始日志。
- “恢复标签栏与窗口”重建自有标签栏，保留文档和组成员，保留单任务栏选择，并关闭单标签自动隐藏。

插件未加载时可用 EXE 安装器的“加载诊断”；保存并退出 Office 后用“修复注册”。这些操作不修改 Office 安全设置。

- 功能区或菜单“最近关闭…”可重开最近 20 个已保存文件，已打开时直接切换；可清空记录，取消关闭不会入列。未保存内容使用 Office 文档恢复。
- 文件的手动宽度和独立窗口选择按本机路径记住；首次保存 / 另存为继承当前选择。右键“重置此文件的标签设置”恢复默认；“…”可清除当前应用全部文件偏好。
- 单任务栏开关、明暗主题、关闭偏好、外观、颜色、默认宽度通常在一秒内同步到其他已打开实例；应用忙时稍后同步。文件手动宽度优先。显隐、停靠不做运行中联动。更新插件仍需重开 Office。
- 融合样式在确认过的顶部功能区底缘补齐背景色，减轻阴影接缝；独立面板、底部停靠、高对比度或不识别的布局保留原有显示。

## 卸载

保存文档并退出 Office，双击 `Uninstall.cmd`，或在 EXE 安装程序中点击“卸载插件”。默认保留设置和日志。需要清除设置时，在解压目录运行：

```powershell
powershell -NoProfile -File scripts/uninstall.ps1 -RemoveSettings
```

`settings.ini` 保存全局设置，`documents.ini` 保存文件偏好和最近关闭的本机路径（格式编码，不是加密），不包含正文，不上传，也不写入脱敏诊断。清空历史可在“最近关闭…”菜单操作。

设置和日志位于 `%LOCALAPPDATA%\openOfficetab`。遇到未显示标签的情况，先重开 Office，再核对 COM 加载项及标签显隐设置。

已验证 Windows 11、Office Home 2024 x64（16.0.20430.20146），200% 缩放。不支持 Office 网页版或 macOS。其他 Office 版本、x86、ARM64 尚未验证。安装程序尚未做代码签名；Release 提供 SHA256SUMS 校验文件，源码可自行构建。

完整说明、截图、源码和问题反馈：[xlennart/openOfficetab](https://github.com/xlennart/openOfficetab)。

新配置默认启用单任务栏；已有明确关闭选择会保留。此设置跨进程同步且重开后保留，独立窗口保留独立任务栏入口。黑色 Office 主题的融合主体、外缘和顶部接缝统一为 `#262626`，深灰主题使用相应深灰，选中标签为 `#323232`。

0.1.6补充：单任务栏模式同步同组的移动、尺寸、最大化、还原、最小化；右上角关闭可选择当前 / 本组全部并记忆。默认明暗主题跟随 Office / 系统，标签外观菜单中可改为手动或仅跟随系统。关闭偏好可从标签设置恢复为每次询问。

拖动窗口或边缘调整大小前临时遮蔽同组后台窗口，保持 Office 文档的可见状态；松开或取消后先同步最终位置和尺寸，再恢复原有外观。独立窗口和其他组不参与。不在 Office 尚未结束的布局回调中调整其他窗口；连续尺寸通知会合并，窗口操作期间暂缓完整文档刷新，结束后恢复。
