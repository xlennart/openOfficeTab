openOfficetab 0.1.2 改进了文档关闭和窗口管理：关闭最后文档后退出 Office，并增加诊断恢复、标签宽度调节和多个标签组。

- 关闭最后文档后退出应用；保留原生保存提示和取消处理，不影响其他独立文档。
- 新建为独立窗口、移到新标签组窗口、拖出 / 跨栏合并、菜单选择目标组；保留原文件、窗口和未保存编辑。
- 保存全部与批量关闭仅处理当前组，取消后停止后续关闭。
- 标签宽度 80–360 DIP，支持固定、标题长度、空间不足时压缩，保留原有圆角样式与应用强调色。
- 加载诊断、脱敏导出、恢复标签栏；安装器增加离线诊断与注册修复。
- 修正 PowerPoint 原生关闭完成时序。

Word、Excel、PowerPoint 已在 Windows 11 / Office Home 2024 x64 实机执行关闭、分组、恢复回归。真实保存提示按钮、鼠标拖拽手感及设置对话框仍需人工验收，详见仓库 `docs/validation-v0.1.2.md`。组成员只在同一应用实例、本次会话生效。

下载安装：保存并退出三款 Office，运行 `openOfficetab-0.1.2-setup-x64.exe`，点击“安装 / 更新”。也可下载 ZIP 完整解压后运行 `Install.cmd`。无需管理员权限，安装器未做代码签名；`SHA256SUMS.txt` 提供校验值。
